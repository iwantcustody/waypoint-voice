How to get a key (about 5 minutes)
1. Go to console.cloud.google.com and sign in. Accept the terms and create a project (any name).
2. Set up billing when asked (Billing → link a billing account). Google needs a card even for the free allowance.
3. Search the top bar for Places API (New) → Enable.
4. APIs & Services → Credentials → Create credentials → API key. Copy it here.
5. Optional but smart: click the key → API restrictions → Restrict key → pick only Places API (New) → Save.
6. Extra safety: APIs & Services → Places API (New) → Quotas, and set the per-day limits to about 35. Then even a leaked key can't run up a bill.
